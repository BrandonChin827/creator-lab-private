# Creator Lab Private

A responsive one-page offer site for Creator Lab Private, the 90-Day AI Authority Partnership.

## Live site

The production URL is published with GitHub Pages after deployment.

## Local preview

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173/>.

## Current behavior

- Responsive desktop and mobile layouts
- Working navigation and CTA links
- Accessible FAQ accordions
- Client-side application validation
- Preview-only form confirmation; no lead data is transmitted or stored externally

## Before accepting applications

1. Connect the form to a secure form or CRM endpoint.
2. Add a privacy policy and terms as appropriate.
3. Configure analytics only after consent and privacy requirements are defined.
4. Connect a custom domain when selected.
